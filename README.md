# gamma overlay

Display movable images on your screen as overlays.
(Custom Desktop Logo but better)
*Windows only*

## download

Go to the [Releases](../../releases) page and download `gammaOverlay.exe`.

> **"Windows protected your PC"?** The exe is not code-signed, so Windows SmartScreen may warn you. Click **More info >> Run anyway**. The full source code is in this repository if you want to check it or build it yourself.

## features

- Show any number of PNG, JPG, GIF or WebP images as borderless, always-on-top overlays
- Drag to move, with snapping to screen edges
- Resize with a corner handle, the mouse wheel, or a precise size slider
- Per-image opacity
- Layout (positions, sizes, opacity) is saved automatically and restored on launch
- Flip, duplicate, and per-image always-on-top
- Lives in the system tray, with optional "Start with Windows"
